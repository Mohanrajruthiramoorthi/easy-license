# Licence platform (Supabase)

- `supabase/migrations/` database, in order: A foundation, B holds and access, C commands and policies
- `supabase/functions/` Edge Functions: `register`, `claim-profile`, `enrol-user` (deploy with verify_jwt on)
- `supabase/tests/foundation.sql` rules test, rolls back everything and ends with "ALL TESTS PASSED (n checks)"
- `admin-dashboard/` React dashboard (see its README to host on Vercel)
- `docs/adl/` decision records
